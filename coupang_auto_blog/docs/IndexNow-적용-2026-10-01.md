# IndexNow 적용 (2026-10-01)

세모링크에 새 글이 게시되면 **IndexNow**로 검색엔진에 즉시 알리도록 적용했다. 이 문서는 동작 방식, 운영 확인 방법, 문제 해결 절차를 정리한다.

## 1. IndexNow란

- 사이트가 "이 URL이 새로 생겼거나 바뀌었다"고 검색엔진에 직접 알리는 공개 프로토콜이다.
- `api.indexnow.org` 한 곳에 보내면 참여 검색엔진(**Bing, Naver**, Yandex, Seznam 등)에 함께 공유된다.
- Google은 IndexNow를 사용하지 않는다. Google은 사이트맵(`sitemap.xml`)과 RSS(`rss.xml`)로 수집한다.
- 전송은 색인 **요청**일 뿐 색인을 보장하지 않는다. 수집 여부는 각 검색엔진이 판단한다.

## 2. 구성

| 항목 | 값 |
|---|---|
| 키 | `4313e3a3b4ab666be2c9becd7766a7fa` |
| 키 파일 | https://semolink.store/4313e3a3b4ab666be2c9becd7766a7fa.txt (`web/public/`에 정적 파일로 둔다) |
| 전송 주소 | `https://api.indexnow.org/indexnow` (POST, JSON) |
| 서비스 코드 | `automation-server/src/services/indexNow.js` |
| 테스트 | `automation-server/test/indexNow.test.js` |
| 배포 커밋 | `e4e5074` |

키는 비밀값이 아니다. 키 파일은 검색엔진이 사이트 소유를 확인하는 데 쓰이므로 **삭제하거나 이름을 바꾸면 안 된다.** 키를 바꿀 때는 `indexNow.js`의 `INDEXNOW_KEY`와 `web/public/{키}.txt`를 함께 바꾼다.

## 3. 전송 시점

| 동작 | 위치 | 전송 URL |
|---|---|---|
| 뉴스 자동 생성(`autoPublish`) — 크론 07:00/18:00 포함 | `POST /api/admin/news/generate` | `/news/{slug}` |
| 관리자에서 뉴스 수정 후 상태가 `published` | `PUT /api/admin/news/:id` | `/news/{slug}` |
| 관리자에서 레시피 수정 후 상태가 `published` | `PUT /api/admin/recipes/:id` | `/recipes/{slug}` |

- 초안(`draft`)은 전송하지 않는다.
- 리뷰는 noindex이며 상품 URL로 리디렉션되므로 전송하지 않는다. 상품 URL도 현재는 전송 대상이 아니다.
- 전송은 백그라운드로 처리한다. IndexNow가 실패해도 뉴스·레시피 게시는 정상적으로 진행된다.
- `NODE_ENV=production`일 때만 전송하므로 로컬 개발 환경에서는 보내지 않는다.

## 4. 배포 후 확인 결과 (2026-10-01)

- 사이트 `https://semolink.store` 200
- 키 파일 200, 내용이 키와 일치함
- 운영 컨테이너에서 RSS 최신 50개 URL을 1회 수동 전송 → **202 Accepted**
  - 202는 정상 접수이며, 검색엔진이 키 파일을 확인하는 중이라는 뜻이다. 이후 전송은 보통 200이 된다.
- automation-server 전체 테스트 102개 통과

## 5. 운영 확인 방법

**전송 로그 보기 (서버)**

```bash
docker logs coupang-automation 2>&1 | grep IndexNow | tail -20
```

- `IndexNow 전송 200` 또는 `202`: 정상
- `IndexNow 전송 403`: 키 파일을 찾을 수 없거나 내용이 다르다 → 키 파일 주소를 확인한다.
- `IndexNow 전송 422`: URL이 다른 도메인이거나 키가 맞지 않는다.
- `IndexNow 전송 429`: 너무 자주 보냈다 → 잠시 후 자연스럽게 회복된다.
- `IndexNow 전송 실패`: 네트워크 오류. 게시에는 영향이 없다.

**Bing Webmaster Tools**

- https://www.bing.com/webmasters → 사이트 추가 → "Google Search Console에서 가져오기"로 등록한다.
- 등록 후 왼쪽 메뉴 **IndexNow**에서 받은 URL 목록과 건수를 볼 수 있다(반영까지 하루 정도 걸릴 수 있다).
- **Sitemaps**에 `https://semolink.store/sitemap.xml`과 `https://semolink.store/rss.xml`이 있는지도 확인한다.

**Naver**

- 네이버는 IndexNow를 받지만 서치어드바이저에 별도의 IndexNow 화면은 없다. RSS 제출 목록과 수집 현황으로 확인한다.

## 7. 수동 일괄 전송 (필요할 때만)

RSS에 있는 최신 URL을 한 번에 다시 보낼 때 서버에서 실행한다. 같은 URL을 자주 반복해서 보내지 않는다.

```bash
docker exec coupang-automation node --input-type=module -e '
import { submitIndexNow } from "./src/services/indexNow.js";
const xml = await (await fetch("https://semolink.store/rss.xml")).text();
const urls = [...xml.matchAll(/<link>(https:\/\/semolink\.store\/[^<]+)<\/link>/g)].map(m => m[1].replaceAll("&amp;", "&"));
console.log(JSON.stringify(await submitIndexNow(urls)));
'
```

## 8. 함께 정리된 검색엔진 제출 현황 (2026-10-01)

| 검색엔진 | 사이트맵 | RSS | IndexNow |
|---|---|---|---|
| Google | 제출 | 사이트맵 메뉴로 제출(처리 대기, 실시간 테스트 성공) | 미지원 |
| Naver | 제출 | 서치어드바이저에 제출 | 자동 전송 |
| Bing | Webmaster Tools 등록 필요 | 등록 시 함께 확인 | 자동 전송 |
