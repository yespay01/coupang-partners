## 현재 운영 범위

세모링크의 현재 핵심 기능은 상품 자동 발견, 실제 가격 관측, 상품 검색, 쿠팡 이동 링크, 방문·검색 성과 분석이다.

| 기능 | 상태 | 비고 |
|---|---|---|
| 상품 자동 발견·수집 | 활성 | 매일 17:50 KST, 회당 최대 100개 |
| 실제 가격 관측 보완 | 활성 | Search API 허용 범위에서 매시간 `:10` 분산 실행 |
| 관리자 가격 관측 화면 | 활성 | 수집 상품과 관측 횟수 중심 |
| 네이버 검색 통계 동기화 | 활성 | 개인 Chrome에서 15분마다 통계 스냅샷 전송 |
| Google Search Console 조회 | 활성 | 서비스 계정 사용 |
| 일일 CTR 진단 | 환경설정에 따라 실행 | 04:20 KST, 개선 후보만 생성 |

| AI 뉴스 생성 | 중지 | 오전·오후 스케줄 비활성 |
| 레시피·뉴스 관리자 작성 | 중지 | 기존 공개 문서 보존 |

상품 수집과 콘텐츠 생성은 독립 기능이다. 리뷰·뉴스 생성을 중지해도 상품 발견과 가격 관측은 계속 실행해야 한다.

## 검색 노출과 메타데이터

- 검색 페이지 제목을 `쿠팡 상품 가격 검색 | 세모링크`로 정리했다.
- 상품 상세 제목은 관측 가격이 있으면 `{상품명} 가격 비교 · {관측가} 관측 | 세모링크`, 없으면 `{상품명} 가격 비교 | 세모링크` 형식이다.
- 상품 상세 설명은 최근 관측가와 최근 90일 실제 관측 범위를 사용한다.
- 상품 상세에 Product JSON-LD와 관측가 기반 Offer 정보를 제공한다.
- 정적 페이지의 가짜 현재 시각 `lastModified`를 제거했다.
- 상품 사이트맵에는 가격 관측값이 한 건 이상 있는 상품만 포함한다.
- 기존 리뷰 URL은 대응하는 상품 URL로 영구 리디렉션해 기존 검색 신호 이전을 유도한다.

## 자동 개선의 현재 의미

자동 실행되는 범위:

- 상품 발견과 가격 관측
- 방문 이벤트 집계
- 네이버 통계 스냅샷 동기화
- 설정된 경우 일일 CTR 데이터 진단과 개선 후보 생성

자동으로 실행하지 않는 범위:

- 근거가 충분하지 않은 제목·화면·상품 순서 변경
- AI 리뷰·뉴스 작성과 게시
- Search Console의 즉시 색인 보장

일일 CTR 진단은 안전을 위해 `proposed` 후보만 만든다. 실제 UI·콘텐츠 변경은 표본, 데이터 품질, 롤백 조건을 검토한 별도 배포 작업이다.
