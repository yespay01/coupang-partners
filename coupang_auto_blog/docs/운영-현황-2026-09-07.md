- 상품 상세 제목은 `{상품명} 가격 변동 | 세모링크` 형식이다.

## 자동 개선의 현재 의미

자동 실행되는 범위:

- 상품 발견과 가격 관측
- 방문 이벤트 집계
- 네이버 통계 스냅샷 동기화
- 설정된 경우 일일 CTR 데이터 진단과 개선 후보 생성

자동으로 실행하지 않는 범위:

- 근거가 충분하지 않은 제목·화면·상품 순서 변경
- AI 리뷰·뉴스 작성과 게시
- Search Console의 즉시 색인 보장

일일 CTR 진단은 안전을 위해 `proposed` 후보만 만든다. 실제 UI·콘텐츠 변경은 표본, 데이터 품질, 롤백 조건을 검토한 별도 배포 작업이다.
