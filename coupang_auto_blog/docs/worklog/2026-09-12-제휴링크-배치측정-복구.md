# 제휴 이동 링크 배치 측정 복구

> 작업일: 2026-09-12 KST
>
> 운영 주소: `https://semolink.store`

## 현재 병목 근거

9월 9~11일 원천 이벤트를 `surface + position + session`으로 집계했다.

| 구분 | 유효 노출 세션 | 적격 이동 세션 | raw 이동 세션 | 고아 이동 세션 |
|---|---:|---:|---:|---:|
| 상세 본문 CTA | 178 | 6 | 6 | 0 |
| 모바일 고정 CTA | 13 | 0 | 0 | 0 |
| 문맥 미상 | 0 | 0 | 248 | 248 |

전체 raw outbound 254세션 가운데 248세션이 `unknown/unknown`으로 남아 배치별 성과를 비교할 수 없었다. 따라서 CTA 문구·배치·상품 순서를 변경하지 않고 측정 복구를 먼저 진행했다.

## 변경 대상

- `AffiliateOutboundLink`의 SSR 초기 `href`에 `surface`, `position`, `content_id`, `product_id`를 포함했다.
- 클릭 이벤트가 정상 실행되면 기존대로 page-view ID까지 포함한 URL로 갱신한다.
- JavaScript가 실행되지 않거나 클릭 처리 전에 이동해도 `/go` 서버가 배치 문맥을 기록할 수 있다.

## 배포 및 검증

- GitHub `main`: `f0e4b89` (`fix: preserve affiliate click placement context`)
- 운영 web 이미지 재빌드·컨테이너 교체 완료
- `coupang-blog-web` 실행, `coupang-automation` healthy 확인
- 공개 상품 페이지에서 다음 SSR 링크를 확인했다.

```text
/go/{linkId}?surface=detail&position=product_detail_primary&content_id=8174473713&product_id=8174473713
/go/{linkId}?surface=detail&position=product_detail_sticky&content_id=8174473713&product_id=8174473713
```

## 예상 선행지표와 확인 시점

- 다음 일일 rollup(2026-09-13 04:20 KST 이후)에서 `unknown/unknown` raw outbound 비율이 감소해야 한다.
- 상세 본문·모바일 고정·관련 상품의 raw 이동이 각각의 `surface + position`으로 분리돼야 한다.
- 배치별 유효 노출 100세션 미만에서는 CTR 차이로 승자를 선언하지 않는다.

## 유지·보강·롤백 조건

- unknown 비율이 현저히 감소하고 새 오류가 없으면 유지한다.
- unknown 비율이 계속 높으면 `/go` 요청을 JavaScript 미실행, 직접 URL, 외부 유입으로 분류하는 측정 보강을 별도 단일 변경으로 진행한다.
- 제휴 이동 실패, 잘못된 대상 URL, 새 추적 오류가 확인되면 기존 `/go/{linkId}` 초기 링크로 즉시 롤백한다.
