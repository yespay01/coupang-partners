# 네이버 서치어드바이저 통계 자동 동기화 가이드

> 현재 방식은 쿠키를 서버에 저장하거나 주기적으로 복사하지 않습니다. 로그인된 개인 Chrome이 네이버 통계를 읽고 통계 스냅샷만 세모링크 서버로 전송합니다.

## 최초 1회 설정

1. Chrome에서 `chrome://extensions`를 연다.
2. 오른쪽 위 `개발자 모드`를 켠다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누른다.
4. `tools/naver-cookie-auto-sync` 폴더를 선택한다.
5. 네이버 서치어드바이저와 세모링크 관리자에 로그인한다.
6. 확장 프로그램 아이콘에서 `지금 동기화`를 누른다.

## 자동 동작

- Chrome 시작 시 즉시 동기화한다.
- Chrome이 실행 중이면 15분마다 동기화한다.
- 네이버 비밀번호, 네이버 쿠키, 세모링크 관리자 쿠키는 서버로 전송하지 않는다.
- 서버에는 기간별 노출·클릭·CTR과 키워드/페이지 통계 스냅샷만 저장한다.
- 네이버 또는 세모링크에서 실제로 로그아웃한 경우에만 다시 로그인한다.

## 정상 여부 확인

1. 세모링크 `/admin/analytics`를 연다.
2. 네이버 검색 데이터의 마지막 동기화 시각을 확인한다.
3. 오래된 경우 확장 프로그램에서 `지금 동기화`를 한 번 실행한다.
4. 계속 실패하면 두 사이트의 로그인 상태와 확장 프로그램 버전을 확인한다.

## 관련 파일

| 파일 | 역할 |
|---|---|
| `tools/naver-cookie-auto-sync/` | Chrome 자동 동기화 확장 프로그램 |
| `tools/naver-cookie-auto-sync/background.js` | 네이버 통계 조회와 주기 실행 |
| `web/app/api/admin/credentials/naver-sa/snapshot/route.ts` | 로그인된 관리자 스냅샷 수신 |
| `automation-server/src/services/naverSearchAdvisor.js` | 스냅샷 저장·조회 및 레거시 폴백 |

과거 수동 쿠키 복사 방식과 서버 쿠키 갱신 방식은 기본 운영 절차가 아니다.
