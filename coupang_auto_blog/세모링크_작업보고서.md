# 세모링크(Semolink) 블로그 디자인 개편 및 기능 업데이트 보고서

**날짜**: 2026년 2월 20일  
**작업자**: Antigravity AI  
**대상**: 30~50대 여성을 위한 프리미엄 라이프스타일 큐레이션 블로그

## 1. 브랜드 및 비주얼 개편 (Rebranding)

### 1.1 브랜드 아이덴티티 수립
- **브랜드명**: '세모링크(Semolink)' - 세상의 모든 링크가 모이는 허브.
- **슬로건**: "더 나은 일상을 기록하다", "Archiviste de la Qualité" (품질의 기록자).
- **디자인 컨셉**: 고가의 종이 매거진(킨포크, 시리얼 등) 느낌의 '에디토리얼 매거진' 스타일.

### 1.2 컬러 및 폰트 시스템
- **컬러 팔레트**: 
  - **Base**: 순백색(#FFFFFF)과 소프트 크림(#FCF9F2) 배경으로 깨끗하고 포근한 느낌.
  - **Accent**: 딥 골드(#C5A059)와 엠버 계열을 사용하여 고급스러운 포인트.
  - **Text**: 딥 차콜(#1A1A1A)과 슬레이트 그레이를 조합하여 가독성과 우아함 동시 확보.
- **타이포그래피**:
  - **Heading**: Noto Serif KR (본명조) - 고전적이고 격조 있는 분위기 연출.
  - **Body**: Noto Sans KR (본고딕) - 현대적이고 깨끗한 읽기 경험 제공.

## 2. 주요 작업 및 기능 개선 사항

### 2.1 메인 페이지 (Main Page) 개편
- **히어로 섹션**: 감성적인 카피와 함께 넓은 여백을 활용한 매거진 커버 스타일 구현.
- **이미지 중심 카드**: 리뷰 카드 비율을 3:4 세로형으로 변경하여 제품 이미지가 돋보이도록 설계.
- **호버 효과**: 이미지 확대 및 부드러운 그림자 효과로 역동적이고 프리미엄한 인터랙션 제공.
- **카테고리 필터링**: 라이브러리 내 데이터를 카테고리별로 즉시 분류하여 탐색 편의성 증대.

### 2.2 상세 페이지 (Detail Page) 최적화
- **레이아웃**: 가로폭을 읽기 편한 사이즈로 제한하고 중앙 정렬하여 텍스트 집중도 향상.
- **이미지 갤러리**: 실제 업로드된 상품 이미지를 시원한 크기로 배치하여 시각적 정보 전달 극대화.
- **구매 유도 섹션**: 하단에 깔끔하게 정돈된 쿠팡 파트너스 링크와 면책 문구 배치.

### 2.3 시스템 및 데이터 연동
- **데이터 로딩 보강**: API 응답 구조가 달라져도 안전하게 리스트를 가져오도록 로직 강화.
- **SEO 적용**: 타이틀과 메타 설명을 '세모링크' 브랜드로 업데이트하여 검색 엔진 최적화.
- **사이버 애니메이션 제거**: 사용자 피드백을 반영하여 눈의 피로를 유발하는 화려한 효과를 삭제하고 정갈한 미니멀리즘 유지.

## 3. 향후 권장 사항
- **이미지 퀄리티**: 3040 타겟에 맞춰 감성적이고 밝은 채광의 연출된 이미지를 사용하는 것이 효과적입니다.

## 4. SEO 개선 작업 (2026년 4월 8일)

### 4.1 Google 태그 설치 (전환 추적)
- `web/app/layout.tsx`에 Google 태그 (GT-K52R4F3K) 추가
- Next.js `Script` 컴포넌트 사용 (`strategy="afterInteractive"`)
- 모든 페이지에 자동 적용

### 4.2 네이버 검색 키워드 추적 개선
- `web/components/VisitorTracker.tsx` 수정
- 네이버 referrer 정책으로 인한 검색어 미수집 문제 대응
- 랜딩 URL의 `nv_query`, `nv_keyword`, `query` 파라미터 추가 확인
- referrer 추출 실패 시 URL 파라미터로 폴백

### 4.3 리뷰 Slug SEO 개선
- `automation-server/src/routes/admin.js` 수정
- 기존: `상품명-{타임스탬프}` 형태 (예: `솔브릭칸예-1708123456789`)
- 변경: `generateUniqueSlug()` 함수 사용 (예: `솔브릭칸예-세탁세제`)
- 타임스탬프 제거로 검색엔진 친화적 URL 생성

### 4.4 리뷰 페이지 메타 타이틀 개선
- `web/app/reviews/[slug]/page.tsx` 수정
- 기존: `상품명 리뷰`
- 변경: `상품명 쿠팡 최저가 리뷰` (CTR 개선 목적)
- OG 이미지: media 배열 첫 번째 이미지 우선 사용
- OG 이미지 크기 명시 (width: 800, height: 600)

### 4.5 사이트맵 이미지 정보 추가
- `automation-server/src/routes/review.js` 수정: sitemap API에 `productImage` 필드 추가
- `web/app/sitemap.ts` 수정: 리뷰 URL에 `<image:image>` 태그 포함
- 네이버 이미지 색인 향상 목적

### 4.6 권장 후속 작업
- 네이버 서치어드바이저에서 `https://semolink.store/sitemap.xml` 제출
- 사이트맵 재제출로 이미지 색인 갱신
