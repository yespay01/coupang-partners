# 세모링크 네이버 통계 자동 동기화

사용자가 이미 로그인한 Chrome에서 네이버 서치어드바이저 통계를 조회해 15분마다 세모링크 서버로 동기화하는 개인용 확장 프로그램입니다. 네이버 비밀번호와 쿠키를 서버에 저장하지 않습니다.

## 최초 1회 설치

1. Chrome에서 `chrome://extensions` 열기
2. 오른쪽 위 `개발자 모드` 켜기
3. `압축해제된 확장 프로그램을 로드합니다` 클릭
4. 이 `naver-cookie-auto-sync` 폴더 선택
5. 네이버 서치어드바이저와 세모링크 관리자에 로그인
6. 확장 프로그램 아이콘을 눌러 `지금 동기화`

## 동작 방식

- Chrome 시작 시 즉시 동기화
- Chrome이 실행 중이면 15분마다 동기화
- 서버는 별도로 30분마다 서치어드바이저 세션 연장
- 네이버 또는 세모링크에서 로그아웃한 경우만 다시 로그인 필요
