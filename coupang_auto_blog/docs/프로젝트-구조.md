# 프로젝트 구조

> 쿠팡 파트너스 자동 블로그 프로젝트 전체 구조

> 중요: 이 문서의 일부 하위 섹션은 Firebase·리뷰 자동 생성 기반 레거시 설명이 남아 있습니다. 현재 운영 상태는 [세모링크 운영 현황](./운영-현황-2026-09-07.md)을 우선 기준으로 사용합니다.

## 📁 전체 디렉토리 구조

```
coupang_auto_blog/
├── web/                      # Next.js 웹 애플리케이션 (공개 사이트 + 관리자 UI + API 프록시)
├── automation-server/        # Express 자동화 서버 (상품수집/가격관측/분석 API + cron)
├── docs/                     # 프로젝트 문서
├── functions/                # Firebase Functions (레거시/이관 잔존)
├── .firebase/                # Firebase 배포 설정 (레거시)
├── firebase.json             # Firebase 설정 (레거시)
├── .firebaserc               # Firebase 프로젝트 정보 (레거시)
├── docker-compose.yml        # 통합 실행 (web + automation-server + postgres + minio)
└── README.md                 # 프로젝트 소개
```

## 🏗️ 현재 운영 아키텍처 (우선 기준)

```
web (Next.js)
  └─ API 프록시 / 관리자 UI / 공개 페이지
      ↓ HTTP
automation-server (Express)
  └─ 쿠팡 상품수집 / 가격관측 / 검색분석 / 관리자 API / cron
      ↓
PostgreSQL (데이터) + MinIO (이미지/파일)
```

AI 리뷰·뉴스 생성 코드는 레거시 호환을 위해 일부 남아 있지만 운영 설정과 관리자 작성·승인 UI에서는 사용하지 않는다.

확인 우선순위:
1. `README.md` (최신 개요/배포 기준)
2. `docker-compose.yml` (실행 대상 서비스)
3. `automation-server/` + `web/` 코드
4. `functions/`는 레거시 참고용

## 🔄 데이터 플로우

### 리뷰 생성 플로우

```
1. collectProductsScheduler (Functions)
   ↓ 쿠팡 API에서 상품 수집
   ↓ Firestore products/ 저장

2. generateReview (Functions)
   ↓ products/에서 상품 선택
   ↓ AI로 리뷰 생성
   ↓ Firestore reviews/ 저장 (status: draft)

3. 관리자 승인 (Web)
   ↓ /admin에서 리뷰 확인
   ↓ 수정 후 게시

4. publishReview (Functions)
   ↓ status → published
   ↓ slug 생성

5. 공개 페이지 (Web)
   ↓ /reviews/[slug] 접근 가능
```
