# 검색 노출·CTR 구조 개선 작업

> 작업일: 2026-09-08 KST
>
> 운영 주소: `https://semolink.store`

## 판단 근거

30일 검색 성과를 유입 단계별로 분리했다.

| 검색엔진 | 노출 | 클릭 | CTR | 판단 |
|---|---:|---:|---:|---|
| Google | 6 | 0 | 0% | 발견·색인·노출 부족 |
| Naver | 20,527 | 197 | 1.0% | 노출 대비 클릭 부족 |

표본 부족을 단순 대기 사유로 보지 않았다. Google은 검색엔진이 유효 상품 URL을 더 쉽게 발견하도록 구조를 넓히고, Naver는 이미 발생하는 노출을 방문으로 전환하는 제목·설명 개선 대상으로 분류했다.

Naver의 노출 상위·CTR 하위 페이지를 연결한 결과, 선별된 저성과 페이지 노출의 100%가 기존 `/reviews/` URL에 남아 있었다. 대표 사례는 다음과 같다.

- 무무막창 관련 기존 URL: 노출 738, 클릭 4, CTR 0.5%, 평균 순위 1.5
- 홈플래닛 선풍기 관련 기존 URL: 노출 284, 클릭 4, CTR 1.4%, 평균 순위 3.0
- 국어별동대 관련 기존 URL: 노출 232, 클릭 2, CTR 0.9%, 평균 순위 3.4

기존 URL은 삭제하지 않고 대응 상품 상세로 `308 Permanent Redirect`를 유지해 검색 신호 이전을 유도한다.

## 반영 내용

### 검색 발견 구조

- 가격 관측값과 검증된 쿠팡 링크가 있는 카테고리 17개를 공개 허브로 생성
- `/collections`와 `/collections/{categoryId}` 추가
- 헤더·푸터·상품 상세 breadcrumb에서 카테고리 내부 링크 제공
- 카테고리별 상품 ItemList JSON-LD와 canonical 제공
- 사이트맵에 카테고리 허브와 카테고리 상세 URL 포함
- 방문 로그의 숫자 경로를 상품명·카테고리명으로 변환

### 검색 CTR

- 상품 상세 제목을 `상품명 + 가격 비교 + 실제 관측 가격` 중심으로 생성
- 관측 가격이 없으면 가격을 만들지 않고 `상품명 + 가격 비교`만 사용
- 설명에는 최근 90일 실제 관측 범위와 쿠팡 현재 판매가 확인 목적을 명시
- 카테고리 제목에는 카테고리명과 실제 공개 상품 수를 포함
- `최저가`, 할인율, 무료배송 등 검증되지 않은 표현은 사용하지 않음

### 방문 후 내부 노출과 전환

- 상품 상세 하단에 같은 카테고리 관련 상품 최대 8개 노출
- 관련 상품 노출·클릭 surface를 `related`로 분리
- 모바일 하단에 현재가 확인 고정 CTA 추가
- 모바일 고정 CTA position을 `product_detail_sticky`로 분리
- 기존 본문 CTA는 유지해 배치별 성과 비교 가능

### 자동 개선 후보

- Google Search Console과 Naver Search Advisor 30일 데이터를 독립적으로 정규화
- 한 검색 소스가 실패해도 다른 소스의 진단은 유지
- 노출 부족과 검색 CTR 부족을 서로 다른 후보로 생성
- 검색 스냅샷이 48시간 이상 오래되면 성과 후보 대신 데이터 최신성 복구 후보 생성
- 전체 평균뿐 아니라 저성과 상위 URL·키워드와 기존 리뷰 URL 비중을 evidence에 저장
- 기존 리뷰 URL 비중이 높으면 영구 리디렉션 유지와 연결 상품 메타 개선을 우선 권고
