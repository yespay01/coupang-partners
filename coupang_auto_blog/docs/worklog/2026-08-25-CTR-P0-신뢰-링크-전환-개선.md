# CTR P0 신뢰·링크·전환 개선 작업 기록

> 작업일: 2026-08-25
> 범위: 로컬 구현과 검증
> 배포: 미실행

## 목적

사용 후기 중심 페이지의 낮은 쿠팡 클릭률을 개선하기 위한 첫 단계로, 제휴 링크 누락과 허위 체험·가격 표현을 차단하고 방문자가 홈에서 바로 쿠팡 현재가를 확인할 수 있는 경로를 만들었다.

## 백엔드

- Partner ID 형식을 `^AF[0-9]+$`로 검증한다.
- Product API가 반환한 `productUrl`은 다시 조립하거나 Deep Link API에 넣지 않는다.
- 긴 제휴 URL은 `link.coupang.com`과 `lptag === settings.coupang.partnerId`를 모두 확인한다.
- Deep Link API에는 일반 `https://(www.)coupang.com/...` URL만 전달한다.
- 새 `coupa.ng` 단축 URL은 같은 응답의 `landingUrl`을 이용해 Partner ID를 검증한다.
- 기존 DB의 동일한 단축 URL만 레거시 호환 목적으로 보존한다.
- `subId` 빈값은 그대로 유지하며 Partner ID로 대체하지 않는다.
- 관리자 수정, 상품 검색, 레시피 상품, 리뷰 생성·게시 경로에 검증을 적용했다.
- 생성문에서 허위 구매·사용·배송·포장 경험을 발견하면 저장하지 않는다.
- 글자 수·톤·금지 문구 검증 실패도 더 이상 경고만 남기고 저장하지 않는다.

## 프론트엔드

- `AffiliateOutboundLink`로 공개 제휴 링크의 관계 속성과 클릭 추적을 통일했다.
- 모든 해당 링크에 `sponsored nofollow noopener noreferrer`를 적용했다.
- 제휴 안내는 페이지의 첫 제휴 링크 전에 한 줄만 노출하고 CTA별 중복 문구를 없앴다.
- 홈 상품 카드는 내부 상품 가이드와 쿠팡 직접 CTA를 분리했다.
- 검색·레시피·신규 상세·레거시 상세 CTA를 공통 링크로 전환했다.
- `최저가`, 회원 전용 할인, 로켓배송 가능처럼 현재 데이터로 입증할 수 없는 문구를 `현재 가격 확인`으로 바꿨다.
- 다이나믹 배너 Partner ID 하드코딩을 제거했다. `NEXT_PUBLIC_COUPANG_PARTNER_ID`가 올바른 형식이 아니면 배너를 숨긴다.

## 콘텐츠와 SEO

- 기본 프롬프트와 3개 템플릿을 실제 사용자 후기에서 사실 기반 상품 선택 가이드로 전환했다.
- 상품명과 카테고리에서 확인되지 않는 성능·재질·효능·가격·배송 정보는 만들지 않도록 했다.
- 과거 DB의 위험한 SEO 메타를 우선 노출하지 않고 현재 안전 규칙으로 다시 생성한다.
- 임의 `Review` 평점 4.5와 `Offer`, `InStock`을 제거하고 사실 기반 `Article` JSON-LD만 제공한다.
- 공개 화면 명칭을 리뷰·솔직 후기 중심에서 상품 모음·상품 선택 가이드 중심으로 정리했다.

## 배포 전 확인

1. 웹 빌드 환경에 `NEXT_PUBLIC_COUPANG_PARTNER_ID`를 실제 Partner ID로 설정한다.
2. 관리자 쿠팡 설정의 `partnerId`와 배너 환경변수가 같은지 확인한다.
3. 테스트 클릭 1건이 쿠팡 리포트의 의도한 채널로 귀속되는지 확인한다.
4. 배포 후 홈·검색·레시피·상세·레거시 상세의 실제 목적지와 클릭 이벤트를 점검한다.
