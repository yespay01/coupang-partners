# Project operating priority

- 사용자가 별도 작업을 지시하지 않으면 분석 데이터에 근거한 구조 개선을 우선한다.
- 기본 개선 순서는 `측정 정상화 → 검색 발견·색인·노출 확대 → 방문 후 상품 노출 확대 → 클릭·수익 최적화`다.
- 표본 부족을 단순 대기로 처리하지 않는다. 측정 누락, 검색 노출 부족, 검색 CTR 부족, 내부 노출 부족을 구분하고 현재 병목을 줄이는 작업을 찾는다.
- 사이트 내 eligible 세션만으로 검색 노출 부족을 단정하지 않는다. 가능하면 Google Search Console, 네이버 서치어드바이저, 색인 범위, 방문 이벤트를 함께 본다.
- 데이터가 불완전할 때 성과 승자를 자동 확정하지 않되, 측정 복구와 비실험적 구조 개선은 계속 진행한다.
